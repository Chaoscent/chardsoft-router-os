Apps Addon

Run apps like Nextcloud, Jellyfin or Vaultwarden, or any Docker image of your own, on the router, each reached by its own name in your network. The addon installs Docker Engine, Docker Compose and the App Manager. It takes a few minutes and needs internet. The router itself never depends on it.

Add your own app

Any Docker image, from Docker Hub or another registry. It gets its own name like the apps above. The router checks it first and lists settings that could harm the router before anything runs.

--

Relative folders (./data) are kept in the app's own folder on the router. Variables you can use: CHARDSOFT_HOST (the app's name), CHARDSOFT_DATA, TZ. The web port is reached through the router's name; you do not need to publish it.
