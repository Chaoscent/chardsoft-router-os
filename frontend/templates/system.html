HTTPS certificate

The dashboard and apps use HTTPS with the router's own certificate authority. Install its certificate on a device once, and browsers trust every router address and app without warnings.

Download certificate

Windows: open the file, Install Certificate, Local Machine, "Trusted Root Certification Authorities". macOS: open it in Keychain Access and set it to Always Trust. iPhone: install the profile, then turn it on in Settings, General, About, Certificate Trust Settings. Android: Settings, Security, Install a certificate, CA certificate.

Two-step login

After the password, signing in also asks for a 6-digit code from an authenticator app on your phone (Aegis, Google Authenticator, 1Password, ...). Someone who learns your password still cannot get in. Lost your phone and the recovery codes? On the router, backend/reset_2fa.py turns it off (see the README).

    Backup & restore

    Download every setting as one file, and upload it here or on another Chardsoft router to restore it. The file contains passwords and VPN keys: encrypt it with a password when you download it. Unconfirmed changes are not included.

      Web shell

      A terminal on the router in the browser (Shell page), off by default. Each session asks for your password and only works from the LAN, never from the internet side.

      Reboot

      Devices lose their connection for about a minute. Unconfirmed changes are reverted by the restart.

      Factory reset

      Erases all settings, accounts, VPN keys and certificates, turns the router's services back to their defaults and reboots into the setup Wi-Fi. Download a backup first if you may want your settings back.

      Uninstall

      Removes Chardsoft Router OS and everything it set up: the Apps Addon with all apps, Wi-Fi, DHCP, DNS, VPNs, firewall rules, the packages it installed and all its files. eth0's address, the hostname and the Wi-Fi country stay, so the Pi is still reachable over its cable. Run it on the router over SSH, ideally over eth0: Wi-Fi and the VPN go off while it runs.
